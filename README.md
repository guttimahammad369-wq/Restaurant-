🍽️ Buddy’s Bites – Restaurant Website

A modern, stylish, and fully responsive restaurant website built using HTML, CSS, and JavaScript.
This project showcases a complete restaurant site with menu sections, chefs, gallery, offers, contact form, and online order form.

🚀 Features

🏠 Beautiful Home Section

📋 Dynamic Full Menu (Veg, Non-Veg, Starters, Burgers, Pizza, Salads, Desserts)

👨‍🍳 Chefs Showcase Section

🖼️ Restaurant Gallery

🎉 Offers & Events Section

📞 Contact Section with WhatsApp & Instagram Links

📝 Working Order Form

🎨 Modern UI with Smooth Hover Effects

📱 Responsive Design (Mobile-friendly)

🛠️ Technologies Used
Technology	Purpose
HTML5	Structure of the Website
CSS3	Styling, Animations & Layout
JavaScript (ES6)	Form Handling & Interactivity
EmailJS	Sending Contact Form Messages
